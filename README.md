##Aprendizado Baseado em Problema 1 - Machine Learning
##Tema: Classificação de riscos e estimativa de eventos climáticos extremos
O trabalho tem como objetivo utilizar algoritmos de Aprendizado Supervisionado para apoiar a gestão de desastres climáticos sob duas perspectivas:

Uma abordagem de Classificação, para categorizar rapidamente o nível de risco do desastre (Baixo, Médio ou Alto).

Uma abordagem de Regressão, para estimar quantitativamente o volume total de população afetada pelo evento.
